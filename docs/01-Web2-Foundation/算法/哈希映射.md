我们从最贴近前端实战的树形结构开始。在开发后台管理系统、组织架构图或多级菜单时，这是一个绝对的高频操作。

## 📝 题目描述
假设你从接口拿到的一组扁平化数据（Flat List），每条数据包含一个 id 和一个 parentId。你需要将其转换成一个嵌套的树形结构（Tree Structure）。
输入数据：
```js
const flatList = [
  { id: 1, name: '根节点', parentId: null },
  { id: 2, name: '子节点1', parentId: 1 },
  { id: 3, name: '子节点2', parentId: 1 },
  { id: 4, name: '孙子节点1', parentId: 2 },
  { id: 5, name: '孙子节点2', parentId: 2 },
  { id: 6, name: '其他节点', parentId: 3 },
];
```
期望输出：
```js
[
  {
    id: 1, name: '根节点', children: [
      {
        id: 2, name: '子节点1', children: [
          { id: 4, name: '孙子节点1', children: [] },
          { id: 5, name: '孙子节点2', children: [] }
        ]
      },
      {
        id: 3, name: '子节点2', children: [
          { id: 6, name: '其他节点', children: [] }
        ]
      }
    ]
  }
]
```
## 🛠️ 前端实战场景
  - 多级菜单渲染：后端为了传输方便通常给扁平数组，前端需要将其转化为树形，才能用递归组件渲染侧边栏。
  - 权限树管理：将用户拥有的权限 ID 列表转化为层级结构，用于显示权限勾选框。
## 💡 引导提示
 - 暴力解法：递归遍历 $\rightarrow$ 时间复杂度较高 $O(n^2)$。
 - 高级解法：利用 `Map` (哈希表) 的引用传递特性。在一次循环中建立所有节点的引用，然后通过 parentId 将它们挂载到对应的 children 数组中 $\rightarrow$ 时间复杂度


 ---

## 概念：
 哈希映射（也叫哈希表、HashMap），是一种键值对（Key-Value） 数据结构，通过哈希函数把「键（Key）」转换成数组下标，快速定位、存取对应的值（Value）。

**特点：**
- 查询 / 插入 / 删除效率极高
理想情况时间复杂度：O(1)（常数级，速度极快）。
- 无序存储
元素存放顺序 ≠ 插入顺序。
- Key 唯一
重复 Key 会直接覆盖旧 Value。
- 支持任意类型键（语言略有差异）
JS/TS、Java、Python 均广泛使用。

## 💡 解题思路分析

很多前端在刚接触这个题时都会陷入 **"递归陷阱"**：下意识地想写递归函数，结果发现代码极其复杂且难以调试。

你这次采用的 **「哈希映射法」** 其实已经是这道题的**最优解**（时间复杂度 $O(n)$），它避开了递归，利用了 JS 对象的引用传递特性。

### 📊 两种解法对比 (Comparison)

| 维度 | 递归解法 (Recursive) | 哈希映射法 (Map-based) |
|------|---------------------|------------------------|
| **思维方式** | 顺序思考：找根 → 找子 → 找孙 | 全局思考：先登记 → 后挂载 |
| **时间复杂度** | $O(n^2)$ <br/>*(每次找子节点都要遍历数组)* | $O(n)$ <br/>*(只需遍历两次数组)* |
| **空间复杂度** | $O(n)$ <br/>*(由于递归调用栈)* | $O(n)$ <br/>*(需一个 Map 存储引用)* |
| **结论** | ❌ 慢，且在深层树中可能导致栈溢出 | ✅ 最优解，工业级标准 |

### 🔑 核心原理

> **JS 对象在内存中只有一份**
> 
> `Map` 记录的、`rootNodes` 记录的以及 `children` 里的对象，全部指向**同一个内存地址**。

**效果：** 在任何一个地方修改该对象（如添加 `children`），所有引用该对象的地方都会同步更新。

## 💻 解法实现

```js
function buildTree(flatList) {
  const map = {};
  const roots = [];

  // Step 1: 建立索引表（登记所有人）
  flatList.forEach(item => {
    map[item.id] = { ...item, children: [] }; // 使用浅拷贝，避免污染原数据
  });

  // Step 2: 建立父子关系（挂载）
  flatList.forEach(item => {
    const node = map[item.id];
    const parent = map[item.parentId];

    if (parent) {
      parent.children.push(node); // 利用引用传递同步更新
    } else {
      roots.push(node); // 没有父亲的即为根节点
    }
  });

  return roots;
}
```
