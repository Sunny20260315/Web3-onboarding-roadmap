# 算法基本概念

## 第一层：什么是"数据结构"？（数据的样子）

数据结构是计算机组织和存储数据的方式，算法是解决问题的一系列步骤。

如果算法是"做菜的方法"，那么数据结构就是"食材的存放方式"。不同的存放方式，决定了你取食材的速度。

### 1. 线性结构

- **数组 (Array)**：最基础的。就像一排有编号的抽屉。
  - **特点**：知道编号（索引）找东西快，但在中间插一个人很慢（后面的人都要往后移）。

- **链表 (Linked List)**：像是一场"寻宝游戏"。每个节点只知道自己的值和下一个人的位置。
  - **特点**：插一个人很快（只要改一下指向），但找第 100 个人很慢（必须从第 1 个开始数）。

- **栈 (Stack)**：像"洗盘子"。最后放进去的盘子最先被洗掉。（LIFO：后进先出）
  - **前端场景**：浏览器的"后退"按钮、函数的调用栈。

- **队列 (Queue)**：像"排队买奶茶"。先来的先买。（FIFO：先进先出）
  - **前端场景**：JS 的事件循环 (Event Loop) 宏任务队列。

- **堆 (Heap)**：像"金字塔"。父节点总是比子节点大（最大堆）或小（最小堆）。
  - **特点**：快速获取最大值或最小值，插入和删除效率高。
  - **前端场景**：优先级队列、Top K 问题、堆排序算法。

### 2. 非线性结构（像网一样）

- **哈希表 (Map/Set)**：像"字典"。通过一个 Key 直接找到 Value。
  - **特点**：极快！只要有 Key，瞬间能定位。

- **树 (Tree)**：像"公司组织架构图"。一个根，多个分支。
  - **重点**：DOM 树、JSON 嵌套结构。

- **图 (Graph)**：像"朋友圈"或"地图"。任何点都可以连接到任何点。
  - **前端场景**：Webpack 的依赖图 (Dependency Graph)。

## 第二层：什么是"算法"？

算法就是一套可重复的步骤。前端面试最常考的几种"套路"：

### 1. 遍历 (Traversal) → "怎么把数据全部走一遍"

- **DFS (深度优先)**：一条路走到底，走不通再回头。
  - **比喻**：走迷宫。

- **BFS (广度优先)**：一层一层往外扩。
  - **比喻**：往水池里丢石头，水波层层扩散。

### 2. 排序 (Sorting) → "怎么把乱序变有序"

不需要死记硬背所有排序，但要懂：**快速排序 (Quick Sort)** 是目前最高效的主流方法。

### 3. 二分查找 (Binary Search) → "怎么快速定位"

- **前提**：必须是有序的。
- **方法**：每次砍掉一半。
- **比喻**：在字典里找单词，直接翻到中间，看目标在左边还是右边。

### 4. 动态规划 (Dynamic Programming) → "记住之前的结果"

- **核心**：把大问题拆成小问题，并把小问题的答案记在笔记本上，下次直接用。
- **比喻**：问你 $1+1+1+1$ 等于几？你说 4。我再加个 $1$ 问你等于几？你不需要重新数，因为你知道刚才的结果是 4，直接 $+1 = 5$。

### 5. 双指针 (Two Pointers) → "两个标记协同工作"

- **核心**：使用两个指针从不同方向或不同速度遍历数组，减少嵌套循环。
- **常见场景**：
  - **对撞指针**：从数组两端向中间移动（如：两数之和、反转数组）。
  - **快慢指针**：一个走得快，一个走得慢（如：判断链表是否有环、删除有序数组重复项）。
- **优势**：将 $O(n^2)$ 的双重循环优化为 $O(n)$ 的单次遍历。
- **比喻**：两个人从操场两端相向而行，或者一个人跑得快、一个人跑得慢，最终会在某个点相遇。

## 第三层：什么是"复杂度"？（衡量好坏的标准）

在面试中，如果你说"我的算法很快"，面试官会问你："复杂度是多少？"。这里有两个概念：

### 1. 时间复杂度 $\text{O}(n)$ → "跑得快不快"

- $\text{O}(1)$：瞬间完成。比如：通过 ID 在 Map 里找人。
- $\text{O}(n)$：线性增长。比如：遍历一个长度为 $n$ 的数组。
- $\text{O}(n^2)$：平方增长。比如：双重循环（数组里套数组）。这是高级前端要极力避免的！
- $\text{O}(\log n)$：极快。比如：二分查找。

### 2. 空间复杂度 $\text{O}(n)$ → "吃不吃内存"

你为了快，是不是多开了一个 Map 来存数据？

如果为了时间快而多用了内存，这就是用 **"空间换时间"**。
