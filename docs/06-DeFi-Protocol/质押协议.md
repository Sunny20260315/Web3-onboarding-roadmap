# 基本概念

## 1. LSD (Liquid Staking Derivatives) — 流动性质押衍生品
概念：它是指用户在质押加密资产（如 ETH）后，获得的具有流动性的生息衍生凭证的总称。

## 2. LST (Liquid Staking Tokens) — 流动性质押代币
概念：它是 LSD 概念下具体的 Token（代币）形态。

常见例子：Lido 协议的 stETH、Rocket Pool 的 rETH。SOL 的 mSOL、jitoSOL

## 3. LSP (Liquid Staking Protocol) — 流动性质押协议
概念：它是指提供流动性质押服务的业务平台、智能合约系统或项目方。

常见例子：Lido、Rocket Pool

# 什么是质押？

## 定义：

用户将 ETH 锁定在以太坊网络中，成为验证者（Validator），参与区块验证和网络安全，获取质押奖励。

## 核心作用：
- 保障 PoS（权益证明）共识机制的安全
- 抑制恶意攻击（罚没 / Slash 机制）
- 减少市场流通量，影响 ETH 供需


我们以以太坊的升级 Pectra（布拉格硬分叉）来举例说明：

阶段	单个验证者的有效质押量	规则说明
Pectra 升级前	固定 32 ETH	你只能质押 32 ETH，多了少了都不算，收益只按 32 ETH 算
Pectra 升级后	32 ETH ~ 2048 ETH	最低 32 ETH，最高 2048 ETH，中间任意金额都可以，收益按你实际质押的有效余额计算

> 以前你要给验证者 “充钱”，只能充 32 的倍数，多出来的钱不产生收益；升级后，你可以给一个验证者充到最多 2048 ETH，这样就不用跑很多个验证者节点，更省事，也提高了资金利用率。

## Lido 解析

- 定义：以太坊上最大的流动性质押协议，解决传统质押 “门槛高、流动性差” 的痛点。
- 核心定位：为散户提供低门槛 ETH 质押服务，同时释放质押资产的流动性。

### Lido 工作流程
1. 用户存入 ETH → 协议按 1:1 发放 stETH（流动性质押凭证）
2. Lido 将用户 ETH 聚合，凑够 32 ETH 后，分配给受信任的节点运营商启动验证者节点
3. 验证者参与质押获取奖励 → 奖励自动累计到 stETH 余额中（Rebase 机制）
4. 用户可随时用 stETH 兑换 ETH，或在 DeFi 中交易、借贷、参与其他协议

### 核心产品： stETH

Lido 发行的流动性质押代币，代表用户质押 ETH 的权益

**关键特性**
- 锚定 ETH：1 stETH ≈ 1 ETH（价格随质押奖励缓慢增值）
- Rebase 机制：质押奖励会自动增加 stETH 余额，用户无需额外操作
- 高流动性：支持在 Curve、Uniswap 等交易所交易，或作为抵押品在 Aave 借贷
