Uniswap 提供多种将交易功能集成到应用程序中的方法。选择合适的方法取决于您在定制、控制和开发资源方面的具体需求。

Uniswap v4 上可以使用自定义链接、Uniswap API、SDK 和智能合约的交换集成路径。

## 自定义链接

对于希望提供兑换功能但又不想管理交易、报价或自定义用户界面的应用程序，您可以使用 URL 查询参数直接链接到 Uniswap 界面。这样，您可以预先填充输入/输出代币、数量，甚至用户界面主题。

在 v2 集成体验中配置 Uniswap 接口 URL 参数，以预填充交换和资金池流。

- V2：支持多跳，但路由相对固定。
- V3（2021）：正式支持自定义路由（custom routes），可指定池、费率、多跳路径。
- V4（2023 草案 / 2025 上线）：通过 Hooks 实现更强的自定义逻辑 / 自定义曲线 / 自定义会计，不只是路由，而是整个池行为可定制。

curl --request POST \
 --url https://api.siliconflow.cn/v1/chat/completions \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer sk-gjqgwnaxojzxghkqyjesjltoedzpgtnqwpilmybffqqtmixd" \
 -d '{
"model": "Pro/zai-org/GLM-4.7",
"messages": [
{"role": "system", "content": "你是一个有用的助手"},
{"role": "user", "content": "你好，请介绍一下你自己"}
]
}'
