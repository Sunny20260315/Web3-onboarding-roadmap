# 钱包地址生成流程 + 核心思想

## 一、核心思想

**非对称加密 + 椭圆曲线签名**

1. 先有**私钥**（自己保管，绝对不能泄露）
2. 私钥单向算出**公钥**（不可逆，公钥推不出私钥）
3. 公钥经过**哈希+编码**，最终变成**钱包地址**
4. 本质：**私钥签名，公钥验签，地址收款**

---

## 二、标准生成完整流程（EVM链通用：ETH/BSC/MATIC等）

1. **生成随机熵（种子）**
   用安全随机算法生成 16~32 字节随机数，作为原始种子。
2. **推导私钥 Private Key**
   种子通过加密算法算出**64位16进制私钥**。
3. **椭圆曲线计算公钥 Public Key**
   EVM统一用 **secp256k1** 曲线
   私钥 → 数学运算 → 得到**完整公钥**
4. **对公钥做 Keccak-256 哈希**
   取公钥**后半段**做 Keccak256 哈希
5. **截取后20字节**
   哈希结果截取最后20字节
6. **拼接 0x 前缀 = 钱包地址**

### 最简链路

**随机种子 → 私钥 → 公钥 → Keccak哈希 → 截20字节 → 0x+地址**

---

## 三、关键特性

1. **单向不可逆**
   地址≠公钥≠私钥，**地址推不出公钥，公钥推不出私钥**
2. **同一套公私钥，通用所有EVM链**
   私钥不变，ETH/BSC/Arb/Base 地址完全一样
3. **私钥=资产所有权**
   谁持有私钥，资产就是谁的
4. **地址只用来收款，公开无害**

---

## 四、助记词版流程（日常钱包流程）

**助记词（12/24个单词）→ 种子 → 私钥 → 公钥 → 地址**
助记词是**私钥明文备份**，丢助记词=丢资产。

---

## 五、不同链小区别

- **EVM(ETH系)**：secp256k1 + Keccak256 → 0x地址
- **SOL**：不同曲线 + Base58编码，地址无0x
- **TRX波场**：公钥处理规则不同，T开头地址
- **BTC**：SHA256+RIPEMD160 生成地址

---

## 六、总结

钱包地址核心就是**基于椭圆曲线非对称加密，由随机数生成私钥，单向推导公钥，再通过哈希压缩得到可公开收款地址，实现签名转账与匿名收款分离**。

## 补充： HD 钱包路径生成

BIP-44 标准的 HD 钱包路径
用来从同一组助记词确定性地派生出以太坊（EVM 系）第一个收款地址
```
m / purpose' / coin_type' / account' / change / address_index
```
对 m/44'/60'/0'/0/0：
m：Master，根节点，由助记词 + 密码 → BIP-39 → 512-bit 种子 → BIP-32 主私钥 + 主链码。
44'：purpose，固定为 44'，表示遵循 BIP-44 标准；' 号 = 强化派生（hardened），不能用公钥推子私钥。
60'：coin_type，60 代表以太坊（ETH）及所有 EVM 链（BSC、Polygon、Arbitrum 等都用 60）。
0'：account，账户索引，从 0 开始；不同账户完全隔离。
0：change，0 = 外部收款地址，1 = 内部找零地址（ETH 基本不用找零）。
0：address_index，地址序号，从 0 开始；同一账户下生成第 N 个地址。
所以：
m/44'/60'/0'/0/0 → ETH 第 0 账户、第 0 个收款地址
m/44'/60'/0'/0/1 → 同账户下第二个地址
m/44'/60'/1'/0/0 → 第 1 个账户的第一个地址
