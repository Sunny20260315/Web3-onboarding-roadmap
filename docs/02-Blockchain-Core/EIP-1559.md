# EIP-1559：以太坊费用市场改革

## 基本信息

| 项目 | 内容 |
|------|------|
| EIP编号 | 1559 |
| 标题 | Fee market change for ETH 1.0 chain |
| 作者 | Vitalik Buterin, Eric Conner, Rick Dudley, Matthew Slipper, Ian Norden, Abdelhamid Bakhta |
| 状态 | Final |
| 类型 | Standards Track |
| 分类 | Core |
| 创建日期 | 2019-04-13 |
| 依赖 | EIP-2718, EIP-2930 |

## 简单摘要

EIP-1559 是一种交易定价机制，包含固定每区块网络费用（被销毁）和动态扩展/收缩区块大小以应对瞬时拥塞。

## 核心机制

### 新交易类型

引入 EIP-2718 交易类型 `0x02`，格式为：

```
0x02 || rlp([chain_id, nonce, max_priority_fee_per_gas, max_fee_per_gas, gas_limit, destination, amount, data, access_list, signature_y_parity, signature_r, signature_s])
```

### 基础费用（Base Fee）

- **定义**：协议层面的基础费用，每区块根据公式动态调整
- **调整机制**：
  - 当区块使用的 gas 超过目标 gas 时，基础费用增加
  - 当区块使用的 gas 低于目标 gas 时，基础费用减少
  - 最大变化幅度受 `BASE_FEE_MAX_CHANGE_DENOMINATOR`（默认为 8）限制
- **处理方式**：基础费用被销毁（burn），不分配给矿工

### 优先费用（Priority Fee）

- **定义**：用户愿意支付给矿工的额外费用，用于激励矿工包含其交易
- **用途**：补偿矿工承担的孤块风险

### 最大费用（Max Fee）

- **定义**：用户愿意支付的总费用上限
- **计算公式**：`max_fee_per_gas >= base_fee_per_gas + priority_fee_per_gas`

### 有效费用（Effective Gas Price）

- **计算公式**：`effective_gas_price = base_fee_per_gas + priority_fee_per_gas`
- **支付规则**：发送者始终支付区块的基础费用 + 交易设置的优先费用

## 设计动机

解决传统拍卖机制的低效问题：

1. **费用波动与社会成本不匹配**：gas 价格波动巨大，但网络实际成本变化很小
2. **用户不必要的延迟**：硬区块 gas 限制导致交易等待多个区块
3. **一级价格拍卖的低效**：复杂的费用估算算法效果不佳，导致频繁的费用过高支付
4. **无区块奖励区块链的不稳定性**：长期来看，仅靠交易费奖励矿工存在安全问题

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| INITIAL_BASE_FEE | 1,000,000,000 (1 Gwei) | 初始基础费用 |
| BASE_FEE_MAX_CHANGE_DENOMINATOR | 8 | 基础费用最大变化分母（每区块最多变化 1/8） |
| ELASTICITY_MULTIPLIER | 2 | 弹性乘数（区块容量可扩展至目标的 2 倍） |

## 优势亮点

1. **可预测的费用**：基础费用变化可预测，钱包可自动设置费用
2. **减少费用过高支付**：用户只需支付实际需要的费用
3. **动态区块大小**：根据网络拥塞自动调整区块容量
4. **ETH 价值捕获**：基础费用销毁减少供应，增强 ETH 价值
5. **降低 MEV 风险**：矿工无法操纵基础费用

## 交易处理流程

1. 用户发送交易，指定 `max_fee_per_gas` 和 `max_priority_fee_per_gas`
2. 交易进入内存池
3. 矿工选择交易时，优先考虑优先费用高的交易
4. 区块打包时，计算有效费用 = 基础费用 + 优先费用
5. 发送者支付有效费用 × gas 使用量
6. 矿工获得优先费用部分，基础费用被销毁
7. 未使用的 gas 按有效费用返还

## 向后兼容性

- **支持旧交易类型**：Legacy 交易和 EIP-2930 交易仍然有效
- **自动转换**：旧交易类型的 `gas_price` 被视为 `max_fee_per_gas` 和 `max_priority_fee_per_gas`
