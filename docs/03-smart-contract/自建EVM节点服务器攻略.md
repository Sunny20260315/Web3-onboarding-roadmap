大型企业往往会搭建自己的节点服务器，同步Ethereum数据，从而提升节点的效率。通常需要搭建多套节点服务器，并使用负载均衡软件将用户请求分发给多个节点服务器。

我将基于文档中“节点搭建教程”的核心内容，按系统配置、软件安装、节点启动的逻辑整理教程笔记，确保步骤清晰、参数说明明确，方便实操参考。

## 节点类型

- Light Node（轻节点）
  只存区块头，不存完整区块和状态
  依赖全节点 / 归档节点查数据
  硬盘：几十 GB，同步快

- Full Node（全节点）
  存所有区块 + 交易，但只保留最近状态（旧状态会删除 / 裁剪）
  查历史状态要重放交易，慢、耗 CPU
  硬盘：约 1TB（2026），同步：几小时～几天
- Archive Node（归档节点）
  存所有区块 + 交易 + 每个区块的完整状态快照
  查任意历史高度（如 15,000,000 块）直接读盘，秒回
  硬盘：15TB+，同步：几天～几周，硬件要求高

### 一、搭建前准备：系统需求（推荐配置）

搭建以太坊节点对服务器硬件和网络有一定要求，需满足以下条件以确保节点稳定同步数据：

- **CPU**：4核及以上（多核心可提升数据同步效率）
- **内存**：至少16GB（节点运行需占用大量内存，避免因内存不足导致同步卡顿或崩溃）
- **硬盘**：推荐SSD固态硬盘，主网节点需2TB以上存储空间（以太坊主网数据量持续增长，SSD可大幅提升数据读写速度，缩短同步时间）
- **网络**：100 Mbps以上带宽（需持续同步区块链数据，带宽过低会导致同步缓慢或中断）

### 二、安装核心软件：Geth（以太坊客户端）

Geth是以太坊官方推荐的客户端，支持搭建全节点并提供RPC接口，以下是不同系统的安装步骤：

#### 1. macOS系统（通过brew安装）

打开终端，依次执行以下命令：

```bash
# 更新brew包管理器
brew update
# 安装以太坊客户端Geth
brew install ethereum
# 验证安装是否成功（显示版本信息即安装完成）
geth version
```

#### 2. Ubuntu系统（通过PPA源安装）

打开终端，依次执行以下命令：

```bash
# 添加以太坊官方PPA源
sudo add-apt-repository -y ppa:ethereum/ethereum
# 更新系统软件包列表
sudo apt update
# 安装Geth客户端
sudo apt install ethereum
# 验证安装是否成功
geth version
```

### 三、启动以太坊主网节点

安装完成后，通过以下命令启动节点并开启RPC接口，支持外部程序调用：

#### 1. 快速启动命令

```bash
geth --http --http.addr "0.0.0.0" --http.port 8545 --http.api personal,eth,net,web3 --syncmode snap
```

#### 2. 关键参数解释（必看）

- `--http`：开启HTTP RPC接口，允许外部应用（如DApp、开发工具）与节点交互
- `--http.addr "0.0.0.0"`：设置RPC监听地址为所有IP，允许外部服务器访问（若仅本地使用，可改为`127.0.0.1`）
- `--http.port 8545`：指定RPC服务端口，默认8545，可根据需求修改（需确保端口未被占用）
- `--http.api personal,eth,net,web3`：开放的RPC API接口，包含账户管理（personal）、区块链数据（eth）、网络状态（net）、通用工具（web3）
- `--syncmode snap`：采用“快照同步”模式，同步速度更快（相比全量同步可节省大量时间和带宽），主网数据同步通常需要1-2天。

### 四、补充说明

1. **高可用配置**：若用于生产环境，需搭建多套节点集群并配置负载均衡（避免单节点故障导致服务中断），每套集群包含多个节点，通过负载均衡分发请求
2. **测试网节点**：若仅用于测试，无需搭建主网节点，可通过 [chainlist.org](https://chainlist.org/) 选择测试网RPC（需勾选“测试网”选项）
3. **节点同步状态**：启动后，节点会自动同步区块链数据，首次同步可能需要数小时至数天（取决于服务器配置和网络速度），可通过终端日志查看同步进度
4. **安全注意事项**：开放`--http.addr "0.0.0.0"`后，需配置防火墙限制访问IP，避免未授权调用；生产环境建议关闭`personal` API（涉及账户私钥相关操作）
